# Sweety – Blood Glucose Tracker

A small web app where a diabetes patient records up to 4 blood glucose readings a day and views daily, month-to-date and monthly reports.

**Stack:** Node.js + Express API, PostgreSQL, React frontend.

The full assignment brief is in [docs/ASSIGNMENT.md](docs/ASSIGNMENT.md).

## Project layout

```
sweety/

├── client/   # React frontend
└── docs/     # Assignment brief, screenshots
```
